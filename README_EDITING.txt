作品集编辑器 V27
====================

推荐使用方法（Windows）：
1. 完整解压整个 ZIP，不要直接在压缩包中运行文件。
2. 进入 site 文件夹。
3. 双击 START_LOCAL_PREVIEW.bat。
4. 黑色窗口应显示类似：
      Serving HTTP on 127.0.0.1 port 8000 ...
   请在编辑期间保持这个窗口开启。
5. 浏览器会自动打开文字编辑器。
6. 顶部选择页面 → 点击“开始编辑” → 直接修改网页文字。
7. 完成后点击“导出 HTML”，把下载的同名 HTML 覆盖回 site/ 文件夹。

如果浏览器显示 ERR_CONNECTION_REFUSED：
- 回到黑色 Portfolio Server 窗口查看错误提示。
- 正常启动后，窗口不会回到普通的 C:\...\site> 命令提示符。
- 可以在命令行分别测试：
      py -3 --version
  或：
      python --version
- 若两条命令都不能显示 Python 3 版本，需要安装 Python 3。

V25 启动器改进：
- 不再只用 `where python` 判断，避免 Windows Store 的 Python 别名误判。
- 优先使用 Windows Python Launcher：py -3。
- 服务器直接运行在当前窗口，启动失败时错误不会被隐藏。
- 8000 端口被占用时自动改用 8010。
- 使用 127.0.0.1，避免部分 localhost 解析问题。

编辑器功能：
- 自动保存本机草稿。
- 撤销 / 重做。
- 桌面 / 平板 / 手机预览。
- 编辑时暂停页面动画，并显示所有 reveal 内容。
- 导出时只写入文字修改，不把动画状态写进 HTML。
- 可以编辑顶部导航文字。

注意：
- 草稿保存在当前浏览器 localStorage，不会自动同步其他电脑。
- 正式修改仍以“导出 HTML → 替换同名文件”为准。

============================
V26 图片编辑模式
============================
编辑器现在支持“文字模式 / 图片模式”。

图片模式使用方法：
1. 启动 START_LOCAL_PREVIEW.bat，打开 editor.html。
2. 点击顶部“图片模式”。
3. 在页面预览中点击想修改的图片。
4. 右侧面板可以：
   - 选择替换图片（PNG / JPG / WebP / GIF）
   - 显示方式：跟随页面样式 / Cover / Contain
   - 调整水平位置 0–100%
   - 调整垂直位置 0–100%
5. 修改会自动保存为本机草稿。
6. 如果只调整 Cover / Contain / 图片位置：点击“导出 HTML”，覆盖 site/ 中同名 HTML 即可。
7. 如果替换了图片：
   a) 先点击“导出 HTML”。
   b) 在右侧图片面板点击“下载替换图”。
   c) 面板会显示“导出后目标路径”，例如：
      assets/images/rigged/new-cover.png
   d) 把下载的图片放进 site/ 下对应路径。
   e) 再用导出的 HTML 覆盖 site/ 中同名页面。

说明：
- 图片模式不会改变页面结构，也不会拖动布局。
- Cover 会填满容器并可能裁切图片；Contain 会完整显示图片但可能留空白。
- 水平 / 垂直位置主要在 Cover 模式下最明显。
- “清除本页草稿”会同时清除文字与图片编辑草稿。
- 替换图片的草稿保存在浏览器 IndexedDB 中，关闭编辑器后仍可继续；清理浏览器站点数据会删除这些草稿。


V27 页面切换修复
----------------
- 每个页面使用独立的编辑会话与草稿命名空间。
- 切换页面时，上一页尚未完成的读取/草稿恢复会立即失效，不会写入下一页。
- 页面加载完成前禁止导出，避免把上一页状态导出成新页面。
- V27 不自动载入 V26 的旧草稿，以避免此前已经发生混杂的草稿继续污染页面。原始 HTML 文件不会受影响。
